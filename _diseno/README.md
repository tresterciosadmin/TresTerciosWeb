# _diseno — material de diseño del sitio

Todo lo que acompaña al sitio pero no es el sitio. La carpeta empieza con `_` para que GitHub Pages (Jekyll) no la publique.

| Carpeta / archivo | Qué es |
|---|---|
| `maquetas/` | Una maqueta por página (`01-home` … `05-contacto`), cada una con `maqueta.html`, capturas, `matriz-de-estilos.md` y `bitacora.md`. Índice: `maquetas/BITACORA.md` |
| `maquetas/02-servicios/bloque-tres-tercios-acordeon.html` | Acordeón de los tres tercios, retirado de la home para la página de Servicios |
| `maquetas/historico/` | Maqueta anterior de Nosotros (Claude Design) |
| `DISEÑO.md` | Reglas de diseño del sitio (no versionado) |
| `premortem/` | Premortem de agosto 2026 (no versionado) |

El sitio publicado está en la raíz del repo. El libro de marca vive en `Marca/MarcaTT`, fuera de este repo.
