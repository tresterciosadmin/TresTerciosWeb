# Botón

Acción principal. Un solo botón primario por pantalla; el resto va como enlace.

**Clases:** `tt-btn`, `tt-btn--primary`, `tt-btn--dark`, `tt-link`

## Ejemplo
```html
<a class="tt-btn tt-btn--primary" href="#contacto">Conversemos</a>
<a class="tt-link" href="#nowcast">Conocer Nowcast Legislativo →</a>
<a class="tt-btn tt-btn--dark" href="#contacto">Quiero acceso anticipado</a>
```

## Regla
El variante --dark existe solo para usarse sobre el clima oscuro. Altura mínima 44 px por accesibilidad.
