# Tarjeta de servicio

Unidad repetible de una grilla de servicios o capacidades.

**Clases:** `tt-card`, `tt-h3`

## Ejemplo
```html
<div class="tt-card">
  <h3 class="tt-h3">Asuntos públicos</h3>
  <p>Mapeo de actores, estrategia de relacionamiento y gestión de agenda ante el sector público.</p>
</div>
```

## Regla
Se usan de a tres en grilla. Si hay más de cuatro, hay que jerarquizar en vez de agregar tarjetas.
