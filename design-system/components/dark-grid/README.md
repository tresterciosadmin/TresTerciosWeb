# Grilla técnica

Fondo de grilla con máscara radial para las zonas de clima oscuro.

**Grupo:** Estructura  
**Clases:** `tt-dark-grid`

## Ejemplo
```html
<section class="tt-dark-grid">…</section>
```

## Regla
Sugiere sistema y medición sin usar un ícono. Solo en clima oscuro y nunca en dos secciones contiguas.
