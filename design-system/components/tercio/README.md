# Tercio

Una de las tres especialidades de la firma, sin nombre de persona: el logo con su tercio activo, el nombre del ángulo y una línea de lo que aporta. Es la versión de `perfil` para cuando todavía no se publican nombres.

**Grupo:** Contenido  
**Clases:** `tt-tercio`, `tt-tercio__tag`, `tt-tercio__linea`

## Ejemplo
```html
<div class="tt-grid-3">
  <article class="tt-tercio">
    <img class="tt-logo" src="../../assets/logo-tercio-1.svg" alt="" width="120">
    <p class="tt-tercio__tag">Análisis político</p>
    <p class="tt-tercio__linea">El proceso legislativo desde adentro: quién firma, qué comisión traba y qué se negocia antes del recinto.</p>
  </article>
  <!-- tercios 2 y 3 -->
</div>
```

## Regla
Los tres tercios llevan el mismo peso visual: nadie es el jefe. Ángulo y orden son los del libro de marca (1): análisis político, datos y tecnología, estrategia. El logo va a 120 px, por encima del mínimo de 72 px de la versión principal.
