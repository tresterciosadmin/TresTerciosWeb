# Barras de cobertura

Muestra continuidad temporal de un conjunto de datos. Clima oscuro.

**Grupo:** Datos  
**Clases:** `tt-cov`, `tt-cov-ax`

## Ejemplo
```html
<div class="tt-cov" aria-hidden="true">
  <span style="height:46%"></span><span style="height:68%"></span><span style="height:100%"></span>
</div>
<div class="tt-cov-ax"><span>2001</span><span>2013</span><span>2026</span></div>
```

## Regla
Comunica densidad y ausencia de huecos, no valores exactos. Si hicieran falta valores exactos, va una tabla.
