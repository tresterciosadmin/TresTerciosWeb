# Flecha circular

Avance y retroceso de un carrusel. 44×44 px por accesibilidad.

**Grupo:** Acciones  
**Clases:** `tt-arrow`

## Ejemplo
```html
<button class="tt-arrow" aria-label="Siguiente">
  <svg viewBox="0 0 24 24" aria-hidden="true"><path d="M9 5l7 7-7 7"/></svg>
</button>
```

## Regla
Trazo de 2px con extremos redondeados: es la única familia de íconos del sistema. En hover se invierte.
