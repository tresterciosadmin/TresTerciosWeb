# Medidor

Una probabilidad, construida con el propio abanico de la marca.

**Grupo:** Datos  
**Clases:** `tt-gauge`, `tt-gauge__val`, `tt-gauge__cap`, `tt-gauge__note`

## Ejemplo
```html
<div class="tt-gauge">
  <img src="../../assets/logo.svg" alt="" width="150">
  <div class="tt-gauge__val">68%</div>
  <div class="tt-gauge__cap">Probabilidad de que el proyecto se convierta en ley.</div>
  <div class="tt-gauge__note">esquema ilustrativo</div>
</div>
```

## Regla
Si la cifra no sale de un cálculo real, lleva la nota «esquema ilustrativo». El sistema no muestra números que no puede sostener.
