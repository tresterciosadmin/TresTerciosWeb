# Dos columnas

Utilidad de layout: columna angosta de texto y columna ancha para la pieza. Colapsa a una sola en 840px.

**Grupo:** Estructura  
**Clases:** `tt-split`

## Ejemplo
```html
<div class="tt-split">
  <div>
    <h2 class="tt-h2">Conversemos</h2>
    <p class="tt-lead">…</p>
  </div>
  <form class="tt-form">…</form>
</div>
```

## Regla
Dos columnas es para una sola pieza al lado de su texto. Para tres cosas del mismo peso se usa `tt-grid-3`.
