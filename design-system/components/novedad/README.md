# Tarjeta de novedad

Un análisis o informe publicado: fecha, tipo, título y dos líneas de por qué importa.

**Grupo:** Contenido  
**Clases:** `tt-novedad`, `tt-novedad__meta`, `tt-novedad__t`, `tt-novedad__p`, `tt-vacio`

## Ejemplo
```html
<article class="tt-novedad">
  <p class="tt-novedad__meta">12 de agosto de 2026 · Análisis</p>
  <h3 class="tt-novedad__t"><a href="#">Título del análisis</a></h3>
  <p class="tt-novedad__p">Dos líneas que expliquen por qué a una empresa le importa.</p>
</article>
```

## Regla
La bajada dice por qué le importa a una empresa, no de qué trata el artículo. Mientras no haya artículos reales, la sección se mantiene desactivada: una lista de novedades vacía comunica abandono.
