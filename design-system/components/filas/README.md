# Filas de seguimiento

Lista compacta de proyectos con su estado y su probabilidad.

**Grupo:** Datos  
**Clases:** `tt-rows`, `tt-row`

## Ejemplo
```html
<div class="tt-rows">
  <div class="tt-row"><b>Proyecto A</b><em>en comisión</em><i>68%</i></div>
</div>
```

## Regla
Mientras el producto no esté publicado, los nombres son genéricos. Nunca citar un expediente real que no se pueda verificar.
