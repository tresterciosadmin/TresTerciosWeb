# Grilla de tres

Utilidad de layout: tres columnas que colapsan a una en 840px.

**Grupo:** Estructura  
**Clases:** `tt-grid-3`

## Ejemplo
```html
<div class="tt-grid-3">
  <div class="tt-card">…</div>
  <div class="tt-card">…</div>
  <div class="tt-card">…</div>
</div>
```

## Regla
Tres es el número del sistema. Si hacen falta cuatro columnas, casi siempre el problema es que hay que jerarquizar el contenido.
