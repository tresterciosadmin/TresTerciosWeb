# Transición de clima

Degradé entre el clima claro y el oscuro. Se usan siempre en par.

**Clases:** `tt-divider`, `tt-divider--out`

## Ejemplo
```html
<div class="tt-divider"></div>
<section class="tt-dark">…</section>
<div class="tt-divider--out"></div>
```

## Regla
Sin ningún elemento gráfico encima. El degradé de salida vuelve siempre al mismo color de entrada.
