# Cifra

Dato duro sobre clima oscuro. Siempre en monoespaciada con cifras tabulares.

**Clases:** `tt-stat`, `tt-stat__n`, `tt-stat__l`

## Ejemplo
```html
<div class="tt-stat">
  <div class="tt-stat__n">1.016.632</div>
  <div class="tt-stat__l">votos analizados</div>
</div>
```

## Regla
Formato de miles con punto en español y coma en inglés. Nunca una cifra sin su etiqueta.
