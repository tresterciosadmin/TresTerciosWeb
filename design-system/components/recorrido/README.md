# Recorrido del método

Los pasos del método en pastillas monoespaciadas. Clima oscuro.

**Grupo:** Datos  
**Clases:** `tt-pipe`

## Ejemplo
```html
<div class="tt-pipe">
  <span>monitoreo continuo</span><b>→</b><span>análisis propio</span><b>→</b>
  <span>alerta temprana</span><b>→</b><span>recomendación</span>
</div>
```

## Regla
Las pastillas van en minúscula, nunca capitalizadas. Se llama «recorrido» y no «pipeline» porque esa palabra está prohibida en el registro de la marca.
