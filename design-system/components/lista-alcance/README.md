# Lista de alcance

Qué incluye un servicio. Vive dentro de FeatureCard pero también suelta, en propuestas y en la plantilla de informe.

**Grupo:** Contenido  
**Clases:** `tt-inc`, `tt-inc__t`

## Ejemplo
```html
<div class="tt-inc">
  <p class="tt-inc__t">Incluye</p>
  <ul>
    <li>Monitoreo de proyectos de ley y de normativa relevante para tu sector</li>
    <li>Alertas cuando un expediente cambia de estado o entra en agenda</li>
  </ul>
</div>
```

## Regla
El viñeteado es un filete de 6px en --bordo-claro, no un bullet ni un ícono. Máximo cinco puntos: más que eso deja de leerse y hay que resumir.
