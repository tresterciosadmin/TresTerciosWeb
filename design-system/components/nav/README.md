# Navegación

Pastilla flotante, más angosta que el contenido para que la marca domine.

**Clases:** `tt-nav`, `tt-brand`

## Ejemplo
```html
<nav>
  <div class="tt-nav">
    <a class="tt-brand" href="#top"><img src="../../assets/logo.svg" alt="" width="38"><span>TRES TERCIOS</span></a>
    <!-- enlaces -->
  </div>
</nav>
```

## Regla
El ancho (--navw) es deliberadamente menor que --maxw. No igualarlos.
