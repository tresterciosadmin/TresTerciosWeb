# Cierre de marca

La firma al pie de una página: el abanico y el nombre en grande. Cierra sin prometer nada.

**Grupo:** Marca  
**Clases:** `tt-lockup`, `tt-lockup__n`

## Ejemplo
```html
<div class="tt-lockup">
  <img src="../../assets/logo.svg" alt="">
  <span class="tt-lockup__n">Tres Tercios</span>
</div>
```

## Regla
Sin frase debajo. Un cierre con una promesa sobre uno mismo debilita lo que ya se probó arriba; la marca sola cierra mejor.
