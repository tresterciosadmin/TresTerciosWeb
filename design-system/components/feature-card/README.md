# Tarjeta insignia

Destaca la oferta principal por encima del resto. Una sola por página.

**Clases:** `tt-feature`, `tt-tag`, `tt-h3`

## Ejemplo
```html
<div class="tt-feature">
  <img src="../../assets/logo.svg" alt="" width="70">
  <div>
    <span class="tt-tag">Oferta insignia</span>
    <h3 class="tt-h3" style="font-size:25px;margin:12px 0 8px">Inteligencia legislativa y regulatoria</h3>
    <p style="color:var(--muted)">Qué proyectos avanzan, qué normas cambian y cómo te afectan — antes de que sea noticia.</p>
  </div>
</div>
```

## Regla
Si hay dos tarjetas insignia en una página, no hay jerarquía: hay dos elementos compitiendo.
