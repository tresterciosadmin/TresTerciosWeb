# Pasos numerados

Una secuencia de tres o cuatro pasos. Es el hermano en clima claro del componente recorrido.

**Grupo:** Contenido  
**Clases:** `tt-pasos`, `tt-paso`, `tt-paso__n`

## Ejemplo
```html
<div class="tt-pasos">
  <div class="tt-paso">
    <span class="tt-paso__n">01</span>
    <h3 class="tt-h3">Diagnóstico.</h3>
    <p>Una reunión para entender qué te regula y qué decisiones dependen de eso.</p>
  </div>
</div>
```

## Regla
No usa Card a propósito: Card tiene hover con elevación y eso comunica que es clickeable. Un paso no es interactivo. El filete superior en bordó es lo que lo separa visualmente de una grilla de servicios.
