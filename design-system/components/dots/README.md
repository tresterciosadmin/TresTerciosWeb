# Indicadores de carrusel

Posición dentro de una secuencia. Navegables, no decorativos.

**Grupo:** Acciones  
**Clases:** `tt-dots`

## Ejemplo
```html
<div class="tt-dots" role="tablist" aria-label="Ir a">
  <button role="tab" aria-selected="true"></button>
  <button role="tab" aria-selected="false"></button>
</div>
```

## Regla
Son botones reales: se puede saltar a cualquier slide. Si el carrusel avanza solo, debe pausarse en hover.
