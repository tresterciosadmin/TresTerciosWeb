# Encabezado de sección

Antetítulo en monoespaciada, título en serif y bajada. Abre toda sección de contenido.

**Clases:** `tt-kicker`, `tt-h2`, `tt-lead`

## Ejemplo
```html
<p class="tt-kicker">Servicios</p>
<h2 class="tt-h2">Una oferta con centro</h2>
<p class="tt-lead">Inteligencia legislativa y regulatoria en el centro; alrededor, las capacidades para convertirla en decisiones.</p>
```

## Regla
El antetítulo nunca repite el título. Sobre clima oscuro, .tt-kicker cambia de color solo por herencia de .tt-dark.
